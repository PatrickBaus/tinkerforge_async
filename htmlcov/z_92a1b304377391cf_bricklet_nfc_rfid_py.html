1""" 

2Module for the Tinkerforge NFC/RFID Bricklet 

3(https://www.tinkerforge.com/en/doc/Software/Bricklets/NFCRFID_Bricklet_Python.html) implemented using 

4Python asyncio. It does the low-level communication with the Tinkerforge ip connection and also handles 

5conversion of raw units to SI units. 

6 

7This module was generated from the Tinkerforge API definitions (https://github.com/Tinkerforge/generators). 

8The descriptions of the functions are taken from the official documentation. Numbers in them can refer to the 

9raw values of the device. The library converts all values to the units given in the "Units" line of each 

10function.

142 async def request_tag_id(self, tag_type: TagType | int, response_expected: bool = True) -> None: 

143 """ 

144 To read or write a tag that is in proximity of the NFC/RFID Bricklet you 

145 first have to call this function with the expected tag type as parameter. 

146 It is no problem if you don't know the tag type. You can cycle through 

147 the available tag types until the tag gives an answer to the request. 

148 

149 Currently the following tag types are supported: 

150 

151 * Mifare Classic 

152 * NFC Forum Type 1 

153 * NFC Forum Type 2 

154 

155 After you call :func:`request_tag_id` the NFC/RFID Bricklet will try to read 

156 the tag ID from the tag. After this process is done the state will change. 

157 You can either register the :attr:`CallbackID.STATE_CHANGED` callback or you can poll 

158 :func:`get_state` to find out about the state change. 

159 

160 If the state changes to *RequestTagIDError* it means that either there was 

161 no tag present or that the tag is of an incompatible type. If the state 

162 changes to *RequestTagIDReady* it means that a compatible tag was found 

163 and that the tag ID could be read out. You can now get the tag ID by 

164 calling :func:`get_tag_id`. 

165 

166 If two tags are in the proximity of the NFC/RFID Bricklet, this 

167 function will cycle through the tags. To select a specific tag you have 

168 to call :func:`request_tag_id` until the correct tag id is found. 

169 

170 In case of any *Error* state the selection is lost and you have to 

171 start again by calling :func:`request_tag_id`. 

172 """ 

173 await self.ipcon.send_request( 

174 device=self, 

175 function_id=FunctionID.REQUEST_TAG_ID, 

176 data=pack_payload((TagType(tag_type).value,), "B"), 

177 response_expected=response_expected, 

178 )

180 async def get_tag_id(self) -> GetTagID: 

181 """ 

182 Returns the tag type, tag ID and the length of the tag ID 

183 (4 or 7 bytes are possible length). This function can only be called if the 

184 NFC/RFID is currently in one of the *Ready* states. The returned ID 

185 is the ID that was saved through the last call of :func:`request_tag_id`. 

186 

187 To get the tag ID of a tag the approach is as follows: 

188 

189 1. Call :func:`request_tag_id` 

190 2. Wait for state to change to *RequestTagIDReady* (see :func:`get_state` or 

191 :attr:`CallbackID.STATE_CHANGED` callback) 

192 3. Call :func:`get_tag_id` 

193 """ 

194 _, payload = await self.ipcon.send_request( 

195 device=self, function_id=FunctionID.GET_TAG_ID, response_expected=True 

196 ) 

197 tag_type, tid_length, tid = unpack_payload(payload, "B B 7B") 

198 return GetTagID(TagType(tag_type), tid_length, tuple(tid))

200 async def get_state(self) -> GetState: 

201 """ 

202 Returns the current state of the NFC/RFID Bricklet. 

203 

204 On startup the Bricklet will be in the *Initialization* state. The 

205 initialization will only take about 20ms. After that it changes to *Idle*. 

206 

207 The functions of this Bricklet can be called in the *Idle* state and all of 

208 the *Ready* and *Error* states. 

209 

210 Example: If you call :func:`request_page`, the state will change to 

211 *RequestPage* until the reading of the page is finished. Then it will change 

212 to either *RequestPageReady* if it worked or to *RequestPageError* if it 

213 didn't. If the request worked you can get the page by calling :func:`get_page`. 

214 

215 The same approach is used analogously for the other API functions. 

216 """ 

217 _, payload = await self.ipcon.send_request( 

218 device=self, function_id=FunctionID.GET_STATE, response_expected=True 

219 ) 

220 state, idle = unpack_payload(payload, "B !") 

221 return GetState(State(state), idle)

223 async def authenticate_mifare_classic_page( 

224 self, page: int, key_number: Key | int, key: bytes | Sequence[int], response_expected: bool = True 

225 ) -> None: 

226 """ 

227 Mifare Classic tags use authentication. If you want to read from or write to 

228 a Mifare Classic page you have to authenticate it beforehand. 

229 Each page can be authenticated with two keys: A (``key_number`` = 0) and B 

230 (``key_number`` = 1). A new Mifare Classic 

231 tag that has not yet been written to can be accessed with key A 

232 and the default key ``[0xFF, 0xFF, 0xFF, 0xFF, 0xFF, 0xFF]``. 

233 

234 The approach to read or write a Mifare Classic page is as follows: 

235 

236 1. Call :func:`request_tag_id` 

237 2. Wait for state to change to *RequestTagIDReady* (see :func:`get_state` 

238 or :attr:`CallbackID.STATE_CHANGED` callback) 

239 3. If looking for a specific tag then call :func:`get_tag_id` and check if the 

240 expected tag was found, if it was not found go back to step 1 

241 4. Call :func:`authenticate_mifare_classic_page` with page and key for the page 

242 5. Wait for state to change to *AuthenticatingMifareClassicPageReady* (see 

243 :func:`get_state` or :attr:`CallbackID.STATE_CHANGED` callback) 

244 6. Call :func:`request_page` or :func:`write_page` to read/write page 

245 """ 

246 page = int(page) 

247 check_range("page", page, 0, 65535) 

248 check_length("key", key, 6) 

249 await self.ipcon.send_request( 

250 device=self, 

251 function_id=FunctionID.AUTHENTICATE_MIFARE_CLASSIC_PAGE, 

252 data=pack_payload((page, Key(key_number).value, list(map(int, key))), "H B 6B"), 

253 response_expected=response_expected, 

254 )

256 async def write_page(self, page: int, data: bytes | Sequence[int], response_expected: bool = True) -> None: 

257 """ 

258 Writes 16 bytes starting from the given page. How many pages are written 

259 depends on the tag type. The page sizes are as follows: 

260 

261 * Mifare Classic page size: 16 byte (one page is written) 

262 * NFC Forum Type 1 page size: 8 byte (two pages are written) 

263 * NFC Forum Type 2 page size: 4 byte (four pages are written) 

264 

265 The general approach for writing to a tag is as follows: 

266 

267 1. Call :func:`request_tag_id` 

268 2. Wait for state to change to *RequestTagIDReady* (see :func:`get_state` or 

269 :attr:`CallbackID.STATE_CHANGED` callback) 

270 3. If looking for a specific tag then call :func:`get_tag_id` and check if the 

271 expected tag was found, if it was not found got back to step 1 

272 4. Call :func:`write_page` with page number and data 

273 5. Wait for state to change to *WritePageReady* (see :func:`get_state` or 

274 :attr:`CallbackID.STATE_CHANGED` callback) 

275 

276 If you use a Mifare Classic tag you have to authenticate a page before you 

277 can write to it. See :func:`authenticate_mifare_classic_page`. 

278 """ 

279 page = int(page) 

280 check_range("page", page, 0, 65535) 

281 check_length("data", data, 16) 

282 await self.ipcon.send_request( 

283 device=self, 

284 function_id=FunctionID.WRITE_PAGE, 

285 data=pack_payload((page, list(map(int, data))), "H 16B"), 

286 response_expected=response_expected, 

287 )

289 async def request_page(self, page: int, response_expected: bool = True) -> None: 

290 """ 

291 Reads 16 bytes starting from the given page and stores them into a buffer. 

292 The buffer can then be read out with :func:`get_page`. 

293 How many pages are read depends on the tag type. The page sizes are 

294 as follows: 

295 

296 * Mifare Classic page size: 16 byte (one page is read) 

297 * NFC Forum Type 1 page size: 8 byte (two pages are read) 

298 * NFC Forum Type 2 page size: 4 byte (four pages are read) 

299 

300 The general approach for reading a tag is as follows: 

301 

302 1. Call :func:`request_tag_id` 

303 2. Wait for state to change to *RequestTagIDReady* (see :func:`get_state` 

304 or :attr:`CallbackID.STATE_CHANGED` callback) 

305 3. If looking for a specific tag then call :func:`get_tag_id` and check if the 

306 expected tag was found, if it was not found got back to step 1 

307 4. Call :func:`request_page` with page number 

308 5. Wait for state to change to *RequestPageReady* (see :func:`get_state` 

309 or :attr:`CallbackID.STATE_CHANGED` callback) 

310 6. Call :func:`get_page` to retrieve the page from the buffer 

311 

312 If you use a Mifare Classic tag you have to authenticate a page before you 

313 can read it. See :func:`authenticate_mifare_classic_page`. 

314 """ 

315 page = int(page) 

316 check_range("page", page, 0, 65535) 

317 await self.ipcon.send_request( 

318 device=self, 

319 function_id=FunctionID.REQUEST_PAGE, 

320 data=pack_payload((page,), "H"), 

321 response_expected=response_expected, 

322 )
